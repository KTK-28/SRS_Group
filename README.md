## 🚀 Instant Deployment on GitHub Pages

This project is built using pure **HTML, CSS, and Vanilla JavaScript** with 100% relative paths. It has **zero server dependencies** and is pre-configured for instant hosting.

### Quick Setup Instructions:
1. Create a new GitHub repository (e.g. `sai-aashiyana`).
2. Upload all files from this directory directly to the **root** of your repository (`index.html` should be at the root).
3. Go to **Settings** > **Pages** in your repository.
4. Set **Source** to `Deploy from a branch`, choose branch `main` (or `master`), folder `/ (root)`, and click **Save**.
5. Your website is live at `https://<your-username>.github.io/<repo-name>/` in ~1 minute!
